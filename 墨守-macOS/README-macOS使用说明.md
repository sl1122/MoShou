# 墨守 · macOS 版使用说明

> 只动坐标、不动文件。零第三方依赖，支持 Apple Silicon（M1/M2/M3/M4）与 Intel Mac，兼容任意中英文存放路径。

## 1. 怎么启动
1. 把整个 `墨守-macOS` 文件夹放到 Mac 上任意位置（支持中英文与空格路径）。
2. 双击 **`启动墨守.command`** 即可自动打开水墨界面。
3. 如果通过微信 / QQ / 压缩包传到 Mac 后首次双击提示「没有执行权限」或「无法验证开发者」：
   - 打开「终端」，输入以下一行命令（把文件夹拖进终端即可自动填路径）：
     ```bash
     chmod +x "/你的路径/墨守-macOS/启动墨守.command"
     ```
   - 或者右键 `启动墨守.command` →「打开」。

## 2. 首次授权（仅需一次）
第一次点击「落子成记」或「归位」时，macOS 会弹出提示请求控制 **Finder（访达）**：
- 点击 **「好 / 允许」** 即可（用于读写桌面图标的 `desktop position` 坐标，绝不会修改或删除任何文件）。
- 若不小心点了拒绝，可前往：**系统设置 → 隐私与安全性 → 自动化**，勾选允许控制 Finder。

## 3. 核心功能
- **落子成记（⌘S）**：扫描并记录此刻 Mac 桌面每个图标的精确坐标，自动留底至 `layouts/`。
- **棋盘拖拽布阵 + 局部单步撤销（⌘Z）**：按住棋盘上任意棋子拖动即可排布或互换，点「撤销一步」局部撤回（`Esc` 全部重置），点「应用布阵」先自动备份原桌面再一键生效。
- **归位（⌘R）**：桌面被弄乱后二次确认还原。
- **回溯**：点击底栏「回溯」或墨历，可实时在棋盘上预览任意历史时刻并一键切回。
- **目录与自定义存址**：点击底栏「目录」可随时在 Finder 中打开或更改快照存储路径（配置记住在 `~/Library/Application Support/MoShou/config.json`）。
- **使用指引与开场回顾**：点击左上角「墨守」旁的 `◎` 圆点可随时重看指引或重播开场动画。
- **极低资源占用**：后台零轮询；点右上角 `✕` 关闭即彻底退出本地服务进程。

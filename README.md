## 一、美学理念 · 东方文房与围棋之境

传统桌面整理工具往往充斥着冰冷的表格、刺眼的广告弹窗与臃肿的后台常驻。「墨守」试图用 **中国传统文房与围棋美学** 重新诠释「桌面秩序」——让每一次记录与归位，都像在素笺棋盘上从容落子。

### 1. 宣纸与夜墨 · 双材质呼吸
- **宣纸（日间）**：取微暖生宣底色 `#F4F0E6`、画心衬底 `#EFE9DC`、松烟浓墨 `#17160F` 与印泥朱砂 `#A93E30`，叠加极淡静态宣纸纤维纹，告别纯白塑料感。
- **夜墨（夜间）**：取深沉宿墨 `#13130E` 与暖宣纸反白 `#EFEADC`，深夜打开柔和不刺眼；双材质切换以 **「墨滴洇染 / 宣纸轻卷」** 自然过渡，零生硬闪烁。

### 2. 六色古矿彩 · 辨物于一眼
棋盘上每一枚代表桌面文件的棋子，皆取色自中国古代传统绘画的 **六味矿物颜料**，柔边微晕，圆心 `0.0px` 精确压在手绘网格交点上：

| 桌面类型 | 古矿彩名 | 宣纸色值 | 夜墨色值 | 意象 |
| :--- | :--- | :---: | :---: | :--- |
| **软件 / 应用** | **青金石** | `#274C8C` | `#3E6FC4` | 沉静深蓝，如群青点染 |
| **文件夹** | **石绿** | `#4E7A5C` | `#6BA077` | 温润青绿，可承纳万物 |
| **压缩包 / 归档** | **紫矿** | `#764D7C` | `#A878B0` | 沉稳紫檀，藏锋纳卷 |
| **文档 / 笔记** | **赭石** | `#8A5B33` | `#B57A45` | 暖褐丹赭，纸墨书香 |
| **系统核心** | **蛤白** | `#C6BCA6` | `#D6CCB8` | 素雅贝白，定盘之基 |
| **其他文件** | **雌黄** | `#B8862F` | `#D6A23C` | 温润暗金，点睛之笔 |

### 3. 开场三幕 · 动静相生的秩序隐喻
每次开启「墨守」（或点击左上角 `◎` 圆点随时重播），界面并非生硬弹出，而是以 **2.26 秒变速三幕水墨动画** 浑然衔接至真实控件：
1. **阴阳旋汇成双键**：一滴浓墨与一缕宣纸色在画心顺时针变速旋舞相抱，随后沿 C1 连续切线丝滑滑落至底部左右，化作 **「落子成记」** 与 **「归位」** 两枚主按钮。
2. **朱砂日轮散三星**：右上角关闭键 `✕` 亮起一轮温润朱砂微光，散出三缕星点弧线飘落至底栏 **「回溯 · 目录 · 夜墨」** 三枚朱砂小点。
3. **六矿彩直飞入局**：六味古矿彩在画心聚绽后兵分两路——主珠直飞棋盘上各自对应颜色棋子的**真实重心**，分灵小珠同步飞向底部对应颜色的**真实图例圆点**，落地瞬间次第唤醒整盘棋局。

### 4. 克制的动效哲学
- **绝不堆砌冗余装饰**：棋盘无祥云、无印章字样、无常驻边框、无高耗能高斯模糊（零 `BlurEffect`）。
- **按钮运笔**：按下时四道极细同心纤毫自中点沿内框流淌绘出，抬起后顺锋隐去；「撤销一步」则采用由外向内聚拢的 **收笔回撤** 涟漪，与「落子/归位」的外扩水晕形成直观的语义区分。

## 二、核心功能

- **落子成记 & 无碰撞精准归位**：
  - 记录当前桌面每个图标的精确坐标并自动留底至三十日墨历；
  - Windows 端内置 **`ApplyDesktopExact`**，写入坐标期间临时解除系统「网格对齐挤位」并在结束后立即还原，彻底杜绝图标碰撞与桌面空洞。
- **棋盘实时拖拽布阵 & 文件夹收纳**：
  - 按住棋盘上任意棋子拖至空位或另一颗棋子**立即松手** = 移动 / 互换位置；
  - 拖至**石绿文件夹棋子**上方**停顿 0.45 秒**或按住 `Shift` = 触发石绿收纳环，松手即可收纳进文件夹；
  - 全程先在棋盘草稿预演，支持局部单步撤销（`Ctrl+Z` / `⌘Z`）与 `Esc` 全部重置，点击「应用布阵」并确认后才触碰真实桌面。
- **内置桌面语义分区引擎（ZoneEngine）**：
  - 自动识别 **系统核心 / 通讯社交（微信、QQ、飞书、钉钉等）/ 办公创作 / 影音媒体 / 游戏娱乐 / 资料归档** 六大分区；
  - 按当前屏幕分辨率（`1080p / 2K / 4K / 带鱼屏`）提供 **「效率分治」「四隅六区」「左翼精排」** 一键预演阵型。
- **历史回溯 & 任意中英文存址**：
  - 点击「回溯」或三十日墨历刻痕，即可在棋盘上实时预览并切回任意历史时刻；
  - 支持自定义任意中英文路径存储快照与历史记录。

## 三、下载与安装

前往右侧 **[Releases 页面](https://github.com/sl1122/MoShou/releases/latest)** 直接下载对应平台安装包：

### Windows（Win10 / Win11）
- **安装版（推荐）**：下载 `墨守-Windows-安装程序.exe`（约 280 KB，零运行库依赖），支持自定义任意中英文目录、创建快捷方式，自带独立宣纸风 `卸载墨守.exe`。
- **便携版**：下载 `墨守-Windows-便携版.exe`（约 200 KB），免安装双击即用。
- *提示*：使用归位/布阵前，请确保桌面右键 → 查看 → 未勾选「自动排列图标」。

### macOS（Apple Silicon M 芯片 & Intel 通用原生应用）
1. 下载 `墨守-macOS.dmg`（约 1.01 MB，纯原生 `Swift + WKWebView` 独立窗口，告别浏览器标签页）。
2. 双击挂载，将 **`墨守.app`** 拖进右侧 **`Applications`**。
3. 首次打开若系统提示未验证开发者，**右键 `墨守.app` → 打开**（或在 `系统设置 → 隐私与安全性` 点击「仍要打开」），并按弹窗允许控制「访达（Finder）」。
4. 请确保桌面右键未勾选「使用叠放」且排序方式为「无」。

## 四、安全与克制

- **纯本地单机运行**：零联网、零统计、零广告、后台零轮询。
- **极低资源占用**：Windows 版原生 WPF 单文件仅 `200 KB` 左右，空闲自动收缩工作集内存；macOS 版采用原生 `Swift + AppKit + WKWebView`，整包仅 `1 MB`，关闭窗口自动退出无残留。
- **数据安全**：除用户显式弹窗确认的「拖入文件夹收纳」外，本工具仅读写桌面图标坐标，绝不删除、改名或上传任何文件。

# 墨守 (MoShou)

宣纸 / 夜墨双材质的跨平台桌面图标布局记忆、实时棋盘布阵与一键归位工具（支持 **Windows** & **macOS**）。

## 核心特性
- **落子成记 & 精准归位**：记录桌面图标精确坐标，无碰撞精准写回（Windows 临时解除网格挤位后再恢复，杜绝空洞）。
- **棋盘实时拖拽布阵**：拖拽棋子排布、互换或悬停 450ms / 按住 `Shift` 收纳进文件夹，支持局部单步撤销（`Ctrl+Z` / `⌘Z`）。
- **内置语义分区引擎**：自动识别系统、通讯（微信/QQ/飞书等）、办公、影音、游戏、归档六大分区，提供分辨率自适应推荐阵型（效率分治 / 四隅六区 / 左翼精排）。
- **轻量纯净**：纯本地运行、零联网、极低内存占用。

## 云端自动打包（Windows EXE + macOS DMG）
进入本仓库 **Actions** → **Build MoShou (Windows EXE + macOS DMG)**，即可下载并排包含 `墨守-Windows-Setup.exe`、`墨守.exe` 与 `墨守-macOS.dmg` 的跨平台发布包 **`MoShou-CrossPlatform-EXE-and-DMG`**。
